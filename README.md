# AI说红楼

辅助阅读《红楼梦》原著的离线互动网页：边读边查人物、理关系、看本回导读，并按「我已读到第 __ 回」严格过滤内容，**默认不剧透**。

底本：**人民文学出版社 120 回本《红楼梦》（程高本系统；俞平伯校订、启功注释，程乙本底本）**。回目、人名、情节顺序依此本整理；脂评本等其他版本差异在页面顶部「版本说明」中提示。

## 快速开始

直接用浏览器打开 `index.html` 即可，无需联网、无需安装、无需构建（用 `file://` 打开也能正常工作）。

如果希望用本地服务器（例如测试不同浏览器），可在项目目录执行：

```bash
python -m http.server 8000
# 然后访问 http://127.0.0.1:8000/
```

## 功能

- **版本说明**：页面顶部醒目提示底本、脂评本差异、副册/又副册归属为通行说法、第 17/18 回分合差异。
- **防剧透阅读进度**：顶部「我已读到第 __ 回」，默认第 1 回。人物经历、人物关系、搜索结果、每回导读只展示截至该回已经发生的内容。
- **折叠提示**：人物还有后续经历时显示「此人后续还有重要经历（发生在第 X 回之后），是否展开查看完整人物线？」；只有主动点击「展开完整人物线」才显示后文，并逐条标出「剧透」。
- **结局隐藏**：人物归宿/结局默认隐藏，读到对应回目或主动点击才会显示。
- **人物库**：核心主角、金陵十二钗正册、副册 / 又副册（红学通行说法）、重要配角；每人含姓名/别名/小名、身份、首次出场及场景、重要经历（标注回目）、人物关系（标注建立回目）、归宿结局（仅依 120 回本正文）。
- **搜索**：按姓名、别名（小名、诨名、字、号）、情节关键词检索；结果同样按阅读进度过滤，未读回目不提前展示。
- **本回导读**：逐回交代新出场人物、关键事件、埋下的伏笔，可前后翻页、跳转到已读回目。
- **三类内容严格区分**：📖 小说描写 / 🔍 作品分析 / 🏛️ 时代背景。作品分析与时代背景单独成页，涉及未读回目时默认折叠。

## 三类内容约定

| 标签 | 含义 |
| --- | --- |
| 📖 小说描写 | 原著正文实写的情节、对话、场景。 |
| 🔍 作品分析 | 红学研究中的常见解读、人物评价、艺术手法分析。属后人观点，非正文。 |
| 🏛️ 时代背景 | 有史料依据的清代社会制度、服饰、饮食、官制、宗法等背景知识。属史实，非小说虚构。 |

## 数据与校验

修改数据后建议依次运行（需 Node.js）：

```bash
node tests/validate-data.mjs --strict   # 数据完整性（字段、回目、名单、回目一致性等）
node tests/test-spoiler.mjs             # 防剧透过滤逻辑单元测试
node tests/test-app-dom.mjs             # 无头 UI 冒烟测试（渲染、折叠、搜索过滤等）
node tests/test-static.mjs --strict     # 页面结构、脚本引用、版本说明与三类标签检查
```

## 说明与边界

- 副册、又副册的完整名单在原著正文中并未全部开列，本页按红学研究通行说法收录，并在页面中标注，不视为正文结论。
- 第 17、18 回在部分程高本印本 / 脂本中合署回目；本页为便于逐回阅读按 120 回分列，`reference/huimu.json` 中有说明。
- 后 40 回按 120 回本正文整理，不评价续书优劣；判词、曲文暗示只放在「作品分析」中。
- 页面完全离线，无外部字体、图片与接口依赖；数据直接写在 `data/*.js` 中，便于审阅和修改。
- 本页是阅读辅助工具，不是原著替代品；如与手中书本有出入，以你的底本为准（页面顶部亦有提示）。
